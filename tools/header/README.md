# Profile header

`assets/header.svg` is generated by `header.py`. It's one self-contained animated SVG (CSS
animations, no scripts, no outside requests), so GitHub plays it as a plain image.

## Regenerate

Needs Python 3.11+ and Pillow with WebP support.

```sh
python tools/header/header.py            # writes assets/header.svg
```

To check a moment of the loop without a browser, freeze it at given times (seconds) and
screenshot each with headless Chrome:

```sh
python tools/header/frames.py assets/header.svg frames/ 1.5 5.6 12
```

## What's in it

A 20 s loop modelled on the hell rounds of Rainy Doom:

| Time | |
|---|---|
| 0–5 s | Rain over the town. A soldier holds the street; the horde walks in from the right. |
| 5 s | Black smoke clumps burst at the camera, golden embers drift, the fog thickens and blurs. The world switches behind it. |
| 6–14 s | Hell: the sky burns, a meteor hits at 9.7 s, the zombies grow horns and their eyes turn purple. |
| 14 s | The same smoke, back to rain. |

The bottom band always stays in front: `FORECAST: RAIN` scrolls the engineer side,
`FORECAST: HELL` the modder side.

## Where to change things

- `RAIN_TEXT`, `HELL_TEXT`: what the band says.
- `KILLS`: when and where each zombie dies. `check_horde()` refuses a schedule where the
  shooter wouldn't be hitting the leading zombie, or where walkers would overlap.
- `TRANSITIONS`: when the smoke rolls in.
- `blots.py`: the smoke clump textures (generated noise, no game assets).
- Animations honour `prefers-reduced-motion`: the banner then holds still on the rainy street.
