# Project cards

`assets/cards/*.svg` are generated by `cards.py`: one self-contained animated SVG per project
(CSS animations, no scripts, no outside requests), in the header's style.

## Regenerate

Needs Python 3.11+ and Pillow with WebP support.

```sh
python tools/cards/cards.py            # writes assets/cards/*.svg
```

## Layout

Each card is 480x300: an animated 480x200 visual over a caption with the title, a tagline and
a chip saying how it was built (`HANDMADE`, `AI-ASSISTED`, `AI-BUILT`). The README shows them
at `width="410"` in one centred paragraph: two fit side by side on desktop, and on a phone each
shrinks to the screen width, one per row.

| Card | Animation | Source |
|---|---|---|
| Rainy Doom | rain and a lightning flash every 9 s above, flames and embers behind the caption | `src/rainy-doom.jpg`, the map's workshop preview |
| T7 Companion | current runs along the logo's traces, pads blink | `src/t7-logo.svg`, from t7_companion |
| Radio Norvinsk | sound waves from the speaker, an ON AIR lamp | `src/radio-norvinsk.jpg`, the mod's thumbnail |
| Homelab | Git flows into the cluster | drawn in `cards.py` |

All animations stop under `prefers-reduced-motion`.

## Badges

`assets/badges/*.svg` come from `badges.py`, in the same style: a dark chip, the brand's icon and
a monospace label. Labels use a forced advance per character (`textLength`), so a badge is the
same width in any monospace font and the stack row stays on one line on desktop.

```sh
python tools/cards/badges.py           # writes assets/badges/*.svg
```

Icons are copied from [Simple Icons](https://simpleicons.org) (CC0 1.0) into `src/icons.json`;
SPT has no brand icon, so it gets a crosshair.
